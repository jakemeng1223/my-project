# 学习笔记

做项目时每一步都要能讲清楚"为什么这么写"。面试官问到项目细节时，答案就在这里。

## v0.1：每日记录的增删改查

### 项目分层：一个请求是怎么走的
```
浏览器 → Controller（接请求）→ Service（业务逻辑）→ Repository（读写数据库）→ 数据库
```
- **`DailyRecordController`**：只负责接收请求、返回结果，不写业务逻辑
- **`DailyRecordService`**：业务规则放这里，比如"同一天保存两次就是更新"
- **`DailyRecordRepository`**：只写接口，Spring Data JPA 根据方法名自动生成 SQL

**为什么要分层？** 每层只管一件事。以后加"AI 一句话记录"功能，只要在 Service 里新增方法，Controller 和 Repository 都不用大改。

### 为什么"保存"用 PUT 而不是 POST
- `PUT /api/records/2026-11-01` 的意思是"把这一天的记录设置成这样"，提交几次结果都一样，这叫**幂等**
- POST 一般用于"新建一条"，重复提交会产生重复数据
- 一天只有一条记录，日期就是天然的标识，所以用 PUT

### 为什么有 `DailyRecordRequest`，不直接用实体类接收参数
- 实体类 `DailyRecord` 里有 `id`、`createdAt` 这类字段，不应该让前端随便改
- 单独定义一个请求对象（DTO），前端能传什么、不能传什么一目了然，校验规则也写在这里

### 参数校验
- `@Min(1) @Max(10)` 写在字段上，Controller 参数加 `@Valid` 才会生效
- 校验失败会抛 `MethodArgumentNotValidException`，由 `GlobalExceptionHandler` 统一转成 400 错误和中文提示

### 统一异常处理
- `@RestControllerAdvice` 拦截所有 Controller 抛出的异常
- 返回 `ProblemDetail`，这是 HTTP 错误响应的标准格式（RFC 9457），前端读 `detail` 字段就能拿到错误信息

### `@Transactional`
- 写操作加 `@Transactional`：方法里任何一步失败，整个操作回滚，不会写一半
- 只读操作加 `readOnly = true`：告诉数据库和框架这里只读，可以做一些优化

### 前端为什么用 `textContent` 而不是 `innerHTML`
- 记录内容是用户输入的。如果用 `innerHTML` 显示，有人在"做了什么"里写一段 `<script>`，就会被当成代码执行，这叫 **XSS 攻击**
- `textContent` 只当纯文本显示，不会执行

### 测试
- `@SpringBootTest` 启动完整应用，`MockMvc` 模拟发 HTTP 请求，不用真的开端口
- 测试用内存数据库 `jdbc:h2:mem:testdb`，`@Transactional` 让每个测试结束后自动回滚，测试之间互不影响

## v0.1.1：全面发展矩阵

### 为什么这里新建用 POST，日记用 PUT
- 日记一天只有一条，日期就是标识，客户端知道该写到哪：`PUT /api/records/2026-11-01`
- 矩阵里的项没有天然标识，两个"睡眠"也可能同时存在，只能让数据库生成 id，所以新建用 `POST /api/items`，返回 `201 Created`；修改时才用 `PUT /api/items/{id}`

### 枚举存成字符串：`@Enumerated(EnumType.STRING)`
- 默认存的是枚举的序号（0、1、2……）。哪天在 `ItemStatus` 中间插入一个新状态，旧数据的序号全部错位，"较差"可能变成"一般"
- 存名字（`"POOR"`）就不会有这个问题，代价是多占一点空间

### 按包分功能，而不是按层分
- 项目结构是 `record/`、`matrix/` 两个包，每个包里有自己的 Controller、Service、Repository
- 另一种是按层分：`controller/`、`service/`、`repository/`。功能多了以后，改一个功能要在好几个目录之间来回跳
- 按功能分，一个功能的代码都在一起，删掉一个功能也只要删一个包

### 雷达图是怎么画的
- 六个方面均匀分布在一圈上，第 i 个方面的角度是 `-90° + i × 60°`（从正上方开始）
- 某个方面得分 s（0～100），对应的点坐标是 `(cos(角度) × R × s/100, sin(角度) × R × s/100)`
- 把六个点连成多边形就是雷达图。用的是浏览器自带的 SVG，没有引入任何图表库

### 公共样式抽到 `css/base.css`
- 两个页面共用颜色、字体、卡片、按钮，抽成一个文件，改一处两边都生效
- 颜色都定义成 CSS 变量（`--seal`、`--ink`），深色模式只需要在 `@media (prefers-color-scheme: dark)` 里重新给变量赋值
